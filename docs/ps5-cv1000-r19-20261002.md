# PS5 Cave cache correction and portable blend r19

pEMU PS5 cv1000-r19-20261002
把 PPSA99998 合并覆盖 /data/homebrew/PPSA99998/，保留 ROM、配置及存档。

最重要修复：r17/r18错误使用 type=3 (WC_GARLIC) 作为CPU核心内存，并错误标为cached。
现改 type=0 (WB_ONION)，用于CPU频繁读取。保持r18独立256MiB核心池及原256MiB主堆。
主机mock无法模拟CPU缓存，这一性能错误未被先前分配器测试发现。实机收益待确认。
新日志应显示 CORE_HEAP ready capacity=256MiB type=0 CPU writeback。

借鉴Salvia：移植精确整数的CV1000固定alpha混合查表/打包饱和加法，仅覆盖
blend && s_mode==0 && d_mode==0，保留透明、裁剪、翻转、同显存反馈及绘制延迟。
其他模式走原函数。PS5构建开启；非PS5保持原路径。没有导入PowerPC DRC、Xenos GPU代码。
Dodonpachi (ddonpach) 不是CV1000，不受此混合特例影响；它可受核心内存缓存修复影响。

日志：CV_LOAD记录CV1000分配/ROM读取/设备初始化时间；CV_PERF每约5秒记录
CPU及设备处理、音频、同步和软件绘制阶段，最多12个窗口/每次载入。
CPU阶段包含内存映射和同步设备回调；异步blitter可能与CPU重叠，不能直接相加估计总工作量。
保留已确认正常的Quit、声音、颜色、显示等待、存档保护；存档实机尚未验证。

验证：交叉编译、SELF完整性、ELF映射及LOAD字节、ZIP CRC；ASan/UBSan验证
65536混合舍入组合、1000000饱和加法、5000图像对比（透明/裁剪/翻转/反馈/时序）。
主机特定固定混合基准耗时约降低25%，不是PS5整机FPS预测。
分配器测试检查type=0、所属池与失败处理；实际PS5缓存效果仍需实机测试。

请分别启动 ddonpach 与 ddpdfk，记录载入时间和游戏中FPS，提供完整pemu_boot.log。
使用与r18相同设置；无需更改CPU时钟或Speed Hacks来对比。
稳定回退：heap-isolation-r18包（其WC内存导致的潜在性能问题会恢复）。
