# PS5 color/audio combined build r15

## Evidence and scope

R13 console now stable; device unavailable logged on every game load. The actual native SDL integration CMake forces SDL_AUDIO=OFF, and generated SDL_config.h defines SDL_AUDIO_DISABLED. Enabling this subsystem is required before diagnosing system-device failure. Rebuilt executable now contains PS5AUDIO_OpenDevice, SDL_AudioInit and sceAudioOutInit/Open/Output/Close imports.

The active EGL default render target is PIPE_FORMAT_R8G8B8A8_UNORM, while native scanout registers VideoOut format0x8000000000000000. The reference PS5 Vulkan WSI registers the same VideoOut format and explicitly exposes only VK_FORMAT_B8G8R8A8_UNORM. This format mismatch is consistent with red/blue inversion in both menu pictures and gameplay. Reference: https://github.com/mihawk-99/PS5_Vulkan/blob/main/driver/ps5vk_wsi.c . Console color correction remains to be verified.

## Changes

SDL native integration enables audio (retaining host-test behavior) and exports SceAudioOut dependency. PS5 driver accepts success and already-initialized0x8026000e; logs hexadecimal platform errors rather than misusing strerror on kernel status; rejects failed mix-buffer allocation. Already-initialized handling follows the working reference: https://github.com/mihawk-99/PS5_RetroArch/blob/main/src/audio_ps5.cpp . Its source is saved in evidence.

Application SDL audio layer zero-initializes wanted/obtained specs and logs init/open success or exact SDL failure to pemu_boot.log. R13 independently owned core mix buffer remains, including failure safety.

Color uses an application compatibility correction for this native G19 backend: wrap source fragment main, encode output.bgra only when drawing default framebuffer, and swap clear red/blue only for default framebuffer. Existing shader work (including CRT) and alpha remain unchanged; offscreen outputs remain RGBA, original RGB565 game pixels and texture uploads unchanged. No CPU conversion or additional fullscreen pass. This is not general BGRA support for the Mesa driver. Remove this compatibility correction if the underlying G19 scanout format is corrected later. GL readback of the default framebuffer would expose encoded bytes; pEMU texture screenshots use the original CPU pixels.

The helper supports the output conventions of bundled shaders, not arbitrary external GLSL output declarations. Existing binary shader paths are unchanged (native PS5 uses source compilation). R14 Quit and R12 input retained.
